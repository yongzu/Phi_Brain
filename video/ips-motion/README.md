# IPS 모션 요약 영상 (Remotion)

IPS 페이지(`ips/`)의 핵심만 담은 약 1분 30초 모션 영상. 1920×1080 · 60fps · 무음(소리는 편집에서 추가 예정).
배포 폴더(`design/` + `ips/`)에 들어가지 않는다.

```bash
cd video/ips-motion
npm install          # 처음 한 번
npm run studio       # 브라우저 미리보기 + 타임라인
npm run render       # out/ips-motion.mp4
```

- 장면 파일: `src/scenes/S01Question.tsx` … 한 장면 = 한 파일, 길이는 각 파일의 `*_DURATION`(초 단위 `sec()`).
- 순서: `src/Video.tsx`의 `SCENES`.
- 디자인 규칙: `src/theme.ts` — 페이지와 같은 잉크 #333 + 흰색, 투명도 100·70·20%, 곡선 `cubic-bezier(0.22, 1, 0.36, 1)`. 형광펜 노랑은 Phi Brain 사용 장면에서만.
- 공통 모션: `src/motion.tsx` — `Reveal`(흐림 → 선명 + 위로), `Scene`(끝 0.4초 흐려지며 퇴장).
- 글꼴: Pretendard(SIL OFL, `public/fonts/`).
