# EWA 회고 페이지 — 진행 상황

최종 갱신: 2026-09-21 / Codex

## 목적과 확정 구성
0~3주차부터 현재까지의 EWA 경험을 1인칭으로 회고한다.
유용성, 완료를 판단하는 기준, 나의 학습과 몰입을 세로 3열로 배치한다.
각 열은 0주차 → 1주차 → 2주차 → 3주차 → 현재 → 앞으로 순서로 이어진다.
마지막에는 더블 다이아몬드와 다른 접근들(가정 검증, 생활 관찰, 기존 방식 비교, 기능 범위 축소)을 비교한다.
실행한 경험과 앞으로의 계획을 구분한다. 주차는 원본 TIL의 0~3주차 표기를 따른다.

## 구현 파일
- EWA/index.html: 회고 본문, 앞으로의 두 방향, 자료 설명과 연결 링크.
- EWA/ewa.css: IPS와 연결되는 회색조·Pretendard·여백, 데스크톱 3열과 모바일 순차 배치.
- EWA/ewa.js: 현재 읽는 구간의 탐색 표시. 본문은 JS 없이도 읽을 수 있다.
- design-pages.yml / assignment-sync.yml: 두 배포 경로 모두 EWA의 HTML/CSS/JS를 포함한다. 이 공유문서는 웹 배포 산출물에서는 제외한다.

## 검증
- 데스크톱 3열과 390px 모바일 화면 확인.
- 가로 넘침 없음. 6개 시기 및 내부 앵커 대상 확인.
- 대안 접근 펼침/접힘 동작, JavaScript 구문 검사, 콘솔 오류 없음 확인.
- 변경 파일 공백 오류 검사 통과.
