# Phi Brain — 디자인 방향

최종 정리: 2026-09-11

## 사용자 지정 방향

- 매우 미니멀하게 구성한다.
- 전반적인 화면과 인터랙션에서 애플 같은 정제된 느낌을 원한다.
- 다음 두 사이트를 레퍼런스로 지정했다.
  - `https://yongzu.github.io/` — 사용자의 자기소개 사이트.
  - `https://www.minwookshin.com/?ref=minimal.gallery`
- 스타일 논의를 거쳐 구현한다. 아래 세부 수치는 아직 제안이며 최종 디자인 승인이 아니다.

## 레퍼런스 관찰

2026-09-11 Codex가 두 사이트 화면과 펼침·접힘 동작을 브라우저에서 확인했다.

- 자기소개 사이트: 흰 바탕, 넓은 여백, 작은 텍스트, log를 펼쳐 단계적으로 탐색하는 구조.
- Minwook Shin 사이트: 좁은 본문 영역, 텍스트 목록, 들여쓰기와 명도 차이, work 섹션 접기·펼치기.
- 레퍼런스의 애니메이션 시간을 측정한 것은 아니다. 아래 시간은 Phi Brain을 위한 제안이다.

## 적용 제안

글과 여백을 중심으로 하고, 필요한 순간에 내용을 펼친다.
사용자의 자기소개 사이트와 연결되는 분위기 속에서 긴 저널을 읽고 쓰기 편한 밀도를 목표로 한다.

| 요소 | 제안 |
|---|---|
| 배경 | 흰색, 선택 상태에만 아주 옅은 회색 |
| 타이포그래피 | 산세리프, 본문 약 16px, 넉넉한 행간. 한글 가독성 우선 |
| 색 | 검정·회색 중심, 의미 있는 상태에 제한적 색 사용 |
| 레이아웃 | 중앙 본문과 넓은 바깥 여백, 검토 시 필요에 따라 두 열 |
| 정보 위계 | 여백·들여쓰기·굵기·명도. 구분선 최소화 |
| 메뉴 | 작은 텍스트로 저널 / 과목 / 실행 |
| 주요 행동 | 정리하기·확정 저장은 찾기 쉽게 강조 |
| 과목 구분 | 과목명 중심. 12가지 색을 기본으로 사용하지 않는 안 |
| 정리 항목 | 카드보다 텍스트 목록 중심 |

## 화면별 제안

- 저널 목록: 날짜, 제목, 과목명. 선택하면 기록 열기.
- 작성: 날짜와 큰 글쓰기 영역, 적은 도구.
- 검토: 정리 항목 중심, 원문 근거 필요 시 펼치기, 데스크톱 비교 모드.
- 과목: 텍스트 과목 목록과 4F별 기록 탐색.
- 실행: 작은 체크 표시, 실행 문장, 보조 과목명.

## 인터랙션 제안

- 펼침·접힘은 약 200ms의 자연스러운 전환.
- hover와 키보드 focus에 은은하지만 인지 가능한 반응.
- 저장 후 작은 저장됨 표시.
- AI 처리 중 원문을 유지하고 정리 중 상태 표시.
- 터치와 키보드로도 기능을 찾을 수 있게 한다. hover만으로 필수 기능을 노출하지 않는다.
- 본문과 상태 정보의 대비를 확보하고, 움직임 줄이기 설정을 고려한다.

## 확정된 스타일 키트 (2026-09-11, 사용자 제공 · Claude Code 반영)

사용자가 `yongzu.github.io`에서 실제로 추출한 스타일 키트(CSS 토큰 + 인터랙션 JS)를 그대로 제공했다.
더 이상 레퍼런스를 보고 짐작하는 단계가 아니라, 이 토큰이 실제 소스다.

- 위치: `design/style-kit/`(`theme.css`, `interactions.js`, `README.md`, `example.html` — 원본 그대로 보존, 재스킨은
  `:root` 토큰만 덮어써서 하고 컴포넌트 규칙은 건드리지 않는다).
- 색상·타이포·이징 등 정확한 값은 `theme.css` §1의 CSS 커스텀 프로퍼티가 유일한 출처다. 이 문서에 수치를 중복 기록하지 않는다.
- 확정된 특징: 폰트 Pretendard, 라이트 전용(`color-scheme:light` 고정 — 다크 모드 없음), 뚜렷한 accent 색 없이 회색조
  중심(과목별 12색 사용 안 함 방향과 일치), 채워진 버튼은 쓰지 않고 전부 고스트/텍스트 버튼, hover-reveal 리스트·아코디언·
  드로어·검색 드롭다운의 인터랙션 타이밍까지 코드로 확정됨(각각 180–520ms, `cubic-bezier` 이징 지정, `prefers-reduced-motion` 대응 포함).
- Claude Code가 이 키트를 적용해 홈 화면 초안을 만들었다: `design/prototypes/home.html`
  (+ 추가 컴포넌트 전용 `design/prototypes/phi-brain.css` — 저널 입력창, 유일한 강조 버튼 "정리하기", 과목 태그, Future
  Item 행. 새 색상 토큰은 추가하지 않고 `theme.css`의 기존 토큰만 사용). 과목은 hover-reveal 리스트, Future Item은
  아코디언, 프로필은 드로어로 구성 — 모두 키트에 이미 있는 패턴을 그대로 재사용했다.
- 이 초안은 정적 프로토타입이며 데이터는 예시(사용자가 실제로 작성했던 BI/AOR/SI 저널 발췌)다. 실제 앱 구현은 아니다.

## 아직 정하지 않은 것

- 최종 화면 배치와 간격의 세부 조정(홈 화면 초안은 나왔으나 다른 화면들 — 과목 상세, 실행 목록 전체 페이지, 검토 화면 —은 아직).
- 로고(현재는 텍스트 워드마크 "Phi Brain"만 사용, 원본 사이트의 Y/\ 마크 같은 로고는 없음).
- 한글·영문 메뉴 표기 최종안(홈 화면 초안은 한글로 작성함: 저널·과목·실행 → "과목" 섹션, "미해결 Future Item" 등).
- 모바일 레이아웃(키트에 일부 반응형 규칙은 있으나 좁은 화면에서의 내비게이션 방식은 미검증).
- 원문 비교 방식(Codex 제안의 데스크톱 2열 비교 모드는 이 키트로 아직 구현 안 함).
- 다크 모드는 키트 자체가 라이트 전용이라 다크 모드를 만들려면 새 토큰 세트가 필요함 — 필요 여부 자체가 미정.
- 구현 시작 시점.
