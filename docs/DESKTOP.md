# Phi Brain 데스크톱 앱 — 계획과 인계

작성: 2026-09-17 / Claude Code · 사용자 확정 범위
이 문서는 **여러 도구(Claude Code · Codex 등)가 나눠 맡기 위한 작업 명세**다. 작업을 맡으면 해당 단계의 "담당"에 자기 이름을 적고,

## 사용자 확정 사항 (2026-09-17)

- **오프라인은 범위 밖.** 온라인 전용 — 앱은 서버가 있어야 동작한다. 오프라인 작성·로컬 저장은 하지 않는다.
- **껍데기는 Electron.** (Tauri는 Rust 도구 사슬이 추가로 필요해 이번에는 채택하지 않음.)
- **화면은 배포된 페이지를 그대로 연다** — `https://yongzu.github.io/Phi_Brain/prototypes/home.html`.
  앱 안에 화면 파일을 복사하지 않는다. 원점(origin)이 그대로여야 서버 CORS·Google 로그인 등록·Gmail 복귀 주소를 건드리지 않고,
  화면을 고칠 때마다 앱을 다시 배포할 필요도 없다.

## 1. 빈 창 띄우기

**목표:** 아이콘을 눌러 창이 뜨고, 그 안에 배포된 Phi Brain 화면이 보인다.

- `desktop/main.js` — `BrowserWindow`로 배포 주소를 연다.
- 창 크기·위치를 기억한다(`userData/window-state.json`).
- 앱 주소 밖으로 나가는 링크(공간예약·Phi LMS·출결 스프레드시트·Figma 보드)는 기본 브라우저로 연다.
- `nodeIntegration: false`, `contextIsolation: true` — 원격 페이지를 여는 창이라 이 둘은 절대 끄지 않는다.

**이 단계에서 로그인은 안 되는 게 정상이다.** Google이 앱 안 브라우저에서의 로그인을 막기 때문 — 단계 2가 그것을 푼다.

**실행:** `cd desktop && npm install && npm start`

## 2. 로그인 길 뚫기 (핵심)

**왜:** Google은 앱에 내장된 브라우저에서의 로그인을 정책으로 막는다("이 브라우저는 안전하지 않을 수 있습니다").
사용자 자격 증명을 앱이 가로챌 수 있기 때문. 우회(UA 위장 등)는 계정 정지 위험이 있어 **하지 않는다.**

**흐름:**
1. 앱에서 "로그인" → 기본 브라우저가 열린다(`shell.openExternal`).
2. 브라우저에서 평소처럼 Google 로그인 → 서버(Worker)가 세션을 만든다.
3. 서버가 `phibrain://auth?code=<일회용 코드>` 로 되돌려 보낸다. 윈도우가 등록된 앱을 깨운다.
4. **앱이 그 코드를 서버에 따로 보내 진짜 세션 토큰으로 교환한다.** 코드는 1회용·짧은 만료(예: 60초).

**왜 코드를 한 번 더 교환하나:** 복귀 주소는 브라우저 기록·로그에 남는다. 토큰을 주소에 직접 실으면 새어 나갈 수 있으므로,
주소에는 1회용 번호표만 싣고 실제 토큰은 별도 요청으로 받는다(OAuth의 authorization code 교환과 같은 이유).

**할 일:**
- 앱: 프로토콜 등록(`app.setAsDefaultProtocolClient('phibrain')`), 두 번째 인스턴스 처리(`second-instance` — 윈도우는 새 프로세스로 URL을 넘긴다), 코드 수신·교환.
- 서버: 데스크톱에서 시작한 로그인을 구분하고, 1회용 코드 발급·교환 엔드포인트를 추가. 코드는 1회 사용 후 폐기, 짧은 만료.
- 화면(`design/prototypes/auth.js`): 앱 안에서 열렸을 때는 GIS 버튼 대신 "브라우저에서 로그인" 경로를 쓰도록 분기.

**완료 기준:** 앱을 껐다 켜도 로그인이 유지되고, 저널 목록이 뜬다.

## 3. Gmail 연결도 같은 길로

2의 경로를 재사용한다. 현재 Gmail 연결은 `returnTo`(허용된 origin)로 브라우저를 되돌려 보내는 구조
(`worker/src/secrets.js`의 `safeReturnTo`) — 여기에 `phibrain://` 복귀를 허용 목록 방식으로 추가한다.

## 4. 앱답게 다듬기

트레이 아이콘, 시작 시 자동 실행, 전역 단축키(저널 바로 쓰기), 메뉴 정리, 새로고침·개발자도구 단축키.

## 5. 세션 토큰을 OS 자격 증명 저장소로

지금은 `localStorage`. 데스크톱에서는 Electron `safeStorage`(윈도우 자격 증명 관리자)에 저장하고, 화면에는 필요할 때만 넘긴다.
2번을 만든 사람이 이어서 하는 게 자연스럽다.

## 6. 설치 파일

`electron-builder`로 Windows 설치 파일(NSIS). **코드 서명이 없으면 설치 시 "알 수 없는 게시자" 경고가 뜬다** —
본인만 쓰면 무시 가능, 배포하려면 코드 서명 인증서가 필요(연 15만원 안팎, 사용자 결정 사항).

## 7. 자동 업데이트

`electron-updater` + GitHub Releases. 화면 내용은 원격이라 자동 반영되므로, 이 단계는 앱 껍데기가 바뀔 때만 의미가 있다.
