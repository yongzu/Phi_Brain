## 문제상황

직접 겪은 불편과 동료 인터뷰(2명)로 확인했다.

### A. 디스코드 저널의 활용성이 낮다 (동료 인터뷰 2명)
- **A1 외부 앱으로 필기하고 정리한다** — 외부 앱에 이미 수업 맥락 및 사고 흐름 등이 포함된 개인만의 정리 체계가 있다.
- **A2 외부 앱과 이중 작성 구조다** — 세션의 맥락과 중요 정보는 외부 앱에 있다. 이를 다시 한 번 정리해 디스코드로 옮긴다.
- **A3 과목별 정리는 외부 앱에 있다** — 디스코드 저널은 일자별 수직 구조라 과목별로 확인할 수 없어, 각자 외부 앱에서 정리한다.

### B. F를 활용하지 못한다 (디스코드 저널 채널)
- **B1 Findings를 다시 보지 않는다** — Findings를 써도 내용이 체화되지 않고 금방 잊힌다. 실제로 적용되지 못한다.
- **B2 Future Item을 두 번 쓴다** — Future Item을 디스코드 저널에 매일 누적해서 쓰거나, 외부 일정관리 앱으로 따로 관리한다.

### C. 과제 관리가 어렵다 (Phi LMS)
- **C1 제출 현황 파악이 어렵다** — 완료 탭에 과제와 셀프 피드백이 섞여 과목별로 파악하기 어렵다.
- **C2 계획을 세우기 어렵다** — 과제의 우선순위, 마감 등을 인지하고 계획을 수립하기 힘들다.
- **C3 필요한 링크가 흩어져 있다** — 피그마·제출 폼·셀프 피드백 링크를 매번 찾아 들어가야 한다.

## 동료 인터뷰 (2명, 2026-09-20)

- 저널링을 매일 쓰지 않는 학습자가 많고, 점점 밀린다.
- 세션 중 노트를 300~400줄 쓴다(수업 내용·전문가 발언을 거의 다 받아 적음). 개인 방식일 수 있다.
- 노트를 다시 정제해 저널로 쓰는 것이 부담이다.
- 노션·옵시디언 등 외부 앱을 쓰기 때문에 저널은 잘 안 쓰고, 쓰더라도 다시 찾지 않는다.

**왜 생기나** — 진짜 저장소가 외부 앱에 따로 있어서(A1) 디스코드 저널은 같은 내용을 두 번 쓰는 사본이 되고(A2), 다시 쓰이지 않으니 쓸 이유가 약해지는 악순환이 생긴다.

**주의** — 2명뿐이다. 추가 인터뷰에서 "외부 앱에 쓴 기록은 다시 보는가"를 확인하면, 문제가 저널이라는 형식에 있는지 기록 전반에 있는지 가를 수 있다.

## 서비스 블루프린트

6단계(세션·노트 → 저널 작성 → 할 일 관리 → 과제·셀프 피드백 제출 → 제출 확인 → 다시 보기) × 학습자 행동 / 접점·지원 시스템 / 백스테이지. 페이지에서 문제 배지 칸에 마우스를 올리거나 누르면 해당 문제가 보인다.

| 단계 | 문제 |
|---|---|
| 1 세션·노트 (백스테이지: 개인만의 정리 체계가 외부 앱에 쌓임) | A1 |
| 2 저널 작성 (외부 앱의 노트를 다시 정리해 디스코드로 옮김 / 날짜순, 과목 태그 없음) | A2 · A3 |
| 3 할 일 관리 | B2 |
| 4 과제·셀프 피드백 제출 | C3 |
| 5 제출 확인 (LMS TO-DO 130개가 날짜순 한 목록) | C1 · C2 |
| 6 다시 보기 (지난 저널은 찾지 않고 개인 노트를 연다) | B1 · A3 |

> 진짜 기록은 개인 앱에 있고, 저널은 두 번 쓰는 사본이 되어 다시 사용되지 않는다.

## 정량 조사

**A. 기록은 다시 볼 때 배움이 된다**
1. 조성범·한송이 (2023), 대학생의 e-포트폴리오 제작 경험 — 정리하지 않으면 깨달음은 흐려진다. (8명 심층 면담)
2. 강인애·유승현·강연경 (2011), 학습성찰도구로서 e-포트폴리오 활성화 — 성찰은 배움을 키우지만(학습조절능력 54.17%, 학습과정 강화 27.08%), 51.21%가 시스템 개선(쉬운 편집 및 관리)을 요구했다.

**B. 그런데 쌓일수록 다시 보기 어렵다**
3. Bruce·Jones·Dumais (2004), Information behaviour that keeps found things found — 보관 방법은 평균 4.87가지로 흩어지고, 안 보이면 잊는다. (핵심 논문)
4. 이수연·이용정 (2020), 대학생 개인정보관리 행태 요인 — 흩어지면 못 찾거나 중복된다. 41.7%가 저장 위치를 기억해서 찾는다.
5. 지윤재·이혜은 (2022), 대학생 파일관리 행태 — 학생은 날짜가 아니라 과목으로 정리한다(파일명 날짜 표기 20% 미만).

**C. 서비스 사례** — 카카오톡 나와의 채팅 태그(2025), Google Classroom 할 일 페이지, 카카오톡 톡서랍.
