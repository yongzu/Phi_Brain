## 2. 페이지 구성 (현재)

01 진행 방식(더블 다이아몬드, 단계 호버) → 02 문제상황(A·B·C 카드) → 03 서비스 블루프린트(문제 배지 호버 팝업) → 04 정량 조사(논문 5편 + 서비스 사례) → 05 정성 조사(인터뷰, 아직 빈 슬롯) → 06 근거를 숫자로 → 07 불편 × 조사 근거(4축 비교) → 08 Discover 결론

문제 라벨: **A 디스코드 저널의 활용성이 낮다 / B F를 활용하지 못한다 / C 과제 관리가 어렵다** (각 항목 A1~A3, B1~B2, C1~C3). 자세한 문장은 README.md 참고.

## 3. 지금 바로 이어서 할 일

### (1) 히어로 문구 확정 — 진행 중
현재 히어로: "저널링, 제대로 활용하고 계신가요?" + "Phi 학습 성찰도구인 저널링. 학습자는 저널링을 매일 작성하지만 그 내용을 제대로 활용하지 못하고 있습니다."

그 아래에 **학습 성찰이 중요한 이유**를 논문 1·2 근거로 붙이기로 했고, 후보 세 가지까지 나왔다.

1. 이유 + 세 수치: "배움은 경험하는 순간이 아니라, 그 경험을 다시 성찰할 때 일어납니다. 성찰 기록을 분석한 연구에서 가장 큰 효과는 학습조절능력 향상 54.17%, 다음은 학습과정 강화 27.08%였고, 설문에서도 자기성찰 향상 66.1%가 1위였습니다."
2. 효과를 풀어 쓰기: "성찰은 어떻게 공부할지 스스로 조절하는 힘(54.17%)과 학습 과정 자체(27.08%)를 키웁니다. 기록을 다시 보지 않으면 이 기회를 놓치게 됩니다."
3. 짧게: "성찰은 배움이 일어나는 지점입니다. 다시 보지 않는 기록은 그 기회를 놓치는 것입니다."

**주의:** 54.17%·27.08%는 성찰저널 240편 분석 결과, 66.1%는 설문 응답이다(논문 2, 2011년, 자기보고).

### (2) 정성 조사 결과 채우기
동료 인터뷰 2명을 이미 진행했는데 페이지에는 아직 "9월 21일 진행 예정"으로 남아 있다.
`ips/ips.js`의 `INTERVIEWS`(카드)와 `INTERVIEW_STATS`(수치) 배열에 넣으면 점선 자리가 실제 내용으로 바뀐다. 형식은 파일의 주석 참고.

확인된 인터뷰 내용:
- 저널링을 매일 쓰지 않는 학습자가 많고 점점 밀린다.
- 세션 중 노트를 300~400줄 쓴다(수업 내용·전문가 발언을 거의 다 받아 적음). 개인 방식일 수 있다.
- 노트를 다시 정제해 저널로 쓰는 것이 부담이다.
- 노션·옵시디언 등 외부 앱을 쓰므로 저널은 잘 안 쓰고, 쓰더라도 다시 찾지 않는다.

### (3) 남은 수치
"셀프 피드백 미확인 칸 수"는 아직 점선(집계 예정). Phi Brain Assignment Manage 데이터로 채운다.

### (4) 다음 단계 (Define)
5 Whys로 근본 원인 좁히기 → 인사이트 문장·HMW 확정 → 반복되는 문제의 우선순위. 페이지의 08 결론에 예고만 되어 있다.

## 4. 지켜야 할 규칙

- **디자인:** 사용자의 다른 저장소 `yongzu/BI`(Phi Programs 리디자인)에서 가져온 문법. 잉크 한 가지(#333) + 흰색, 위계는 투명도(100·70·20%)로만. 새 색을 추가하지 않는다. 폰트는 Pretendard.
- **인터랙션:** 스크롤 등장, 좌측 목차, 카드 호버 미리보기, 사이드 패널(←/→·Esc), 블루프린트 문제 팝업. 호버 시 다른 요소를 흐리게 하지 않고 올린 것만 살짝 커진다.
- **작업 방식:** 로컬에서 고치고 사용자가 확인한 뒤, **요청할 때만** 커밋·푸시한다.
- **저장소 규칙:** 작업 후 `docs/STATUS.md`에 기록을 남긴다(`AGENTS.md` 참고).
- **문체:** 한국어, 단정한 서술체. 과장·홍보 표현을 쓰지 않는다.
- **근거:** 수치에는 출처(논문 번호)를 붙인다. 확인하지 않은 내용은 쓰지 않는다.

## 5. ChatGPT에 붙여 넣을 프롬프트

아래를 그대로 복사해서 새 대화에 붙여 넣으면 된다.

```
너는 내 IPS(Iterative Problem Solving) 과제를 이어서 도와줄 조력자야. 한국어로 단정한 서술체로 답해줘.

[맥락]
나는 Phi Design Institute 학습자이고, 12과목의 학습 저널(디스코드)과 과제 제출(Phi LMS)을 과목별로 정리하는 "Phi Brain"이라는 도구를 만들고 있어.
이번 3라운드 과제로 더블 다이아몬드의 Discover 단계를 웹페이지로 정리했고, 지금까지의 모든 내용은 아래 문서 두 개에 있어. 먼저 읽고 시작해줘.
- https://github.com/yongzu/Phi_Brain/blob/main/ips/README.md  (Discover 내용 요약)
- https://github.com/yongzu/Phi_Brain/blob/main/ips/HANDOFF.md  (인계 문서: 진행 상황·남은 일·규칙)
페이지: https://yongzu.github.io/Phi_Brain/ips/

[현재 상태]
- 문제상황을 A(디스코드 저널의 활용성이 낮다) · B(F를 활용하지 못한다) · C(과제 관리가 어렵다)로 정리했고, 동료 인터뷰 2명 결과를 반영했어.
- 정량 조사는 논문 5편과 서비스 사례 3건을 정리했어.
- 서비스 블루프린트(6단계 × 3레인)에 문제가 생기는 위치를 표시했어.

[다음에 할 일]
1. 히어로 문구 확정: "학습 성찰이 왜 중요한가"를 논문 1·2 근거로 한두 문장으로 넣으려고 해. HANDOFF.md의 후보 세 가지를 보고 의견과 대안을 줘. (수치: 학습조절능력 향상 54.17%, 학습과정 강화 27.08% — 성찰저널 240편 분석 / 자기성찰 향상 66.1% — 설문)
2. 정성 조사 결과를 페이지에 넣을 수 있게 인터뷰 카드 3장과 수치 3개 형태로 정리.
3. 그다음 Define 단계: 5 Whys로 근본 원인 좁히기, 인사이트 문장과 HMW 질문 확정.

[요청]
- 수치를 쓸 때는 출처(논문 번호)와 조사 방식을 함께 밝혀줘. 확인되지 않은 내용은 추측해서 쓰지 마.
- 먼저 1번부터 하나씩 진행하고, 내가 확인한 다음에 다음으로 넘어가자.
- 코드 수정이 필요하면 어떤 파일의 어느 부분을 어떻게 바꿀지 알려줘. (파일: ips/index.html, ips/ips.css, ips/ips.js)
```
