## 2. 페이지 구성 (현재)

히어로 → **01 핵심 문제**(문제 1 큰 카드 + 부차 문제 2·3) → **02 서비스 블루프린트**(문제 배지 1-1~3-3 호버·클릭 팝업) → **03 정량 조사**(논문 5편, 카드 호버 미리보기 + 사이드 패널) → **04 정성 조사**(인터뷰 6명, 질문 6박스 · 3개씩 2줄) → **05 제출 데이터**(과제·셀프 피드백 표 2개) → **06 Discover 결론**(문제 1 근거 세 칸) → **07 진행 방식**(더블 다이아몬드, 단계 호버 · 맨 아래로 이동)

- **2026-09-26 문제 중심 개편:** 도구별 A·B·C 분류를 버리고 사용자가 정의한 핵심 문제 3개로 재구성했다. 페이지 전체가 문제 1로 수렴한다.
  - 문제 1(가장 중요): 저널을 다시 보지 않아 학습 성찰이 일어나지 않는다 — 1-1 다시 보지 않음(옛 B1) · 1-2 기록 중심이 외부 앱(옛 A1+A2) · 1-3 과목별로 찾을 수 없음(옛 A3)
  - 문제 2: 해야 할 행동과 과제를 수행하지 않는다 — 2-1 Future Item 완료 미추적(옛 B2) · 2-2 셀프 피드백을 미루다 놓침(인터뷰 질문 05)
  - 문제 3: LMS로 과제 현황과 우선순위를 알 수 없다 — 3-1~3-3(옛 C1~C3)
  - 근거 연결: 03 논문 = 문제 1(A 왜 중요한가 · B 왜 생기는가), 04 인터뷰 = 질문별 문제 번호 라벨, 05 제출 데이터 = 문제 2·3(셀프 피드백 56.0%가 문제 2 근거).
  - 07 결론은 문제 1만 다룬다: 선언문 → 근거 세 칸(왜 중요한가·실제로 일어나는가·왜 생기는가) → Define에서 이어서. 해법 표현과 **Develop 메모는 삭제**(되살리지 말 것). 히어로의 논문 02 수치(54.17%·27.08%)는 결론 "왜 중요한가" 칸으로 옮겼다.
- 01~05 각 섹션 끝에 **검은 박스 한 줄 인사이트**가 있다(흰 글씨, 가운데 정렬).
- 1920×1080 한 화면에 각 섹션이 모두 담기도록 맞춰 뒀다(1680px 이상에서 본문 폭 1400px). 섹션 내용 높이는 456~907px.
- 좌측 목차를 누르면 해당 섹션이 **화면 정중앙**에 오도록 스크롤한다.
- 커서는 Phi Brain 프로토타입과 동일(`ips/cursor-arrow.svg`·`cursor-pointer.svg`·`cursor-text.svg`).
- 등장 애니메이션(아래→위)은 본문 전 요소에 적용돼 있다(푸터 포함).

### 지난 버전에서 **삭제한** 것 (되살리지 말 것)

## 3. 데이터와 계산 기준 (건드릴 때 주의)

**과제** — 마감 전 빈칸 제외, o·지각·x만 집계. 509건 중 제때 478(93.9%), 지각 22(4.3%), 미제출 9(1.8%). A반 13명 221건 / B반 15명 288건.

**셀프 피드백** — 시트의 o·x를 그대로 세되, A·B 분반 수강 과목 차이와 수업이 열리지 않은 과목(SI) 때문에 **1·2주차 미제출에서 각각 70칸**을 뺀다. 결과: 408 / 728 = 56.0%, 미제출 320(44.0%). 주차별 86.1% → 57.1% → 19.0%(3주차는 한 과목만 마감, 25.0%).

원본 데이터는 `수료조건 확인 대시보드.xlsx`(사용자 로컬, 저장소에는 없음). 수치를 바꾸려면 이 기준을 그대로 유지해야 표와 인사이트가 어긋나지 않는다.

## 4. 남은 일

1. **Define 단계** — 문제 1 "왜 다시 보지 않는가"를 5 Whys로 좁히기 → 인사이트 문장 확정 → HMW 질문 → 문제 2·3과의 관계 정리. 07 결론에 원인 단서 3개와 예고가 있다.
2. **인터뷰 인원수 집계** — "주 1회 이하로 다시 봤다", "Findings를 외부 앱에서 관리했다", "셀프 피드백을 놓친 경험이 있다"를 `n/6명`으로 세어 05 정성 조사에 넣기. 집계 전에는 숫자를 쓰지 말고 "일부 응답자 / 반복해서 나타났다"로 둔다.
3. 필요하면 06 제출 데이터에 사람별 편차(최다 24개 · 최소 6개)를 추가.

## 5. 지켜야 할 규칙

- **디자인:** 사용자의 다른 저장소 `yongzu/BI`에서 가져온 문법. 잉크 한 가지(#333) + 흰색, 위계는 투명도(100·70·20%)로만. **새 색을 추가하지 않는다.** 폰트는 Pretendard.
- **인터랙션:** 스크롤 등장, 좌측 목차(중앙 정렬 이동), 카드 호버 미리보기, 사이드 패널(←/→·Esc), 블루프린트 문제 팝업. 호버 시 다른 요소를 흐리게 하지 않고 올린 것만 살짝 커진다.
- **작업 방식:** 로컬에서 고치고 사용자가 확인한 뒤, **요청할 때만** 커밋·푸시한다.
- **저장소 규칙:** 작업 후 `docs/STATUS.md`에 기록을 남긴다(`AGENTS.md` 참고).
- **문체:** 한국어, 단정한 서술체. 과장·홍보 표현을 쓰지 않는다.
- **근거:** 수치에는 출처(논문 번호 또는 대시보드)와 집계 기준을 붙인다. 확인하지 않은 내용은 쓰지 않는다.
